# Monster Idle World — V1

RPG Idle original feito com HTML, CSS e JavaScript.

## Rodar localmente
Abra `index.html` no navegador. Para testar PWA/service worker, use um servidor local (ex.: VS Code Live Server) ou GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório.
2. Envie todos os arquivos mantendo as pastas.
3. Em Settings → Pages, selecione a branch principal e a pasta `/root`.
4. Acesse o endereço fornecido pelo GitHub.
